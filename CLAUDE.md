# Magyar — особистий тренажер угорської (PWA)

Проєкт для одного користувача. Без акаунтів, без бекенду, без монетизації.
Мова інтерфейсу й коментарів для користувача — українська; код і коментарі в коді — англійською.

## Стек
- Next.js 15 (App Router), TypeScript, React 19. Без Tailwind — `src/app/globals.css` з CSS-змінними, light/dark.
- Dexie (IndexedDB) — прогрес. `ts-fsrs` — розклад повторень. Web Speech API — вимова.
- PWA: `public/manifest.json` + ручний `public/sw.js` (реєструється лише в production; усі шляхи рахує від власного `scope`, тож працює і в корені, і під `/Magyar/`).
- **Установка на телефон — GitHub Pages**: https://way1ong.github.io/Magyar/ — статична збірка (`npm run build:static` → `scripts/build-static.mjs`: `MAGYAR_STATIC=1`, `output: "export"`, `basePath: "/Magyar"`, `trailingSlash`, API-маршрут на час збірки відкладається вбік, `out/.nojekyll`). Публікує `.github/workflows/pages.yml` на кожен push у `main`, тож злиття PR = оновлення застосунку на телефоні (SW підхоплює нову версію при наступному відкритті). У статичній збірці нема бекапу на ноутбук (`IS_STATIC`/`NO_LAPTOP` у `backup.ts`) — лише «Поділитися»/експорт. Посилання на manifest/sw беруть `NEXT_PUBLIC_BASE_PATH` (задає `next.config.ts`; у превʼю визначено як порожній).
- Бекап: `src/app/api/backup/route.ts` (Next API, пише `backups/` на ноутбуці, без автентифікації — лише домашня мережа) + `src/lib/backup.ts` (автобекап з головної, Web Share). У превʼю-збірці серверного шляху нема (`IS_PREVIEW`).
- Аудіо ВИМКНЕНО (`AUDIO_ENABLED = false` у `src/lib/config.ts`): Piper ковтає короткі слова, системний TTS без угорського голосу. Ховає «Вимову», вкладку й сіяння «Диктанту». Інфраструктура лишилась: `public/audio/<itemId>.mp3` + маніфест `content/audio.json` (`scripts/audio-manifest.mjs`), генерація `scripts/gen-audio.sh` (Piper); у превʼю аудіо йде по одному JSON на пакет (`preview/dist/audio/<pack>.json`, {id: base64}, бо артефакт тримає ≤ 511 файлів). Коли буде якісний голос (Google Cloud TTS hu-HU WaveNet, Azure, записи з Wikimedia Commons) — згенерувати файли, увімкнути прапорець.

## Дві бази — не плутати
- **Контент** (`content/*.json`) — слова, фрази, суфіксальні патерни; `content/guide.json` — довідка (особливості мови, терміни), `content/audio.json` — маніфест аудіо. Read-only на телефоні, редагується в репо, бандлиться в застосунок (`src/lib/content.ts`). Перевірка: `npm run content:check`.
- **Прогрес** (IndexedDB `magyar`, `src/lib/db.ts`) — таблиці `cards` (стан FSRS), `reviews` (повний журнал — ніколи не видаляти, по ньому перенавчаються параметри FSRS), `meta`.

## Ключові правила
- `id` елемента контенту стабільний і ніколи не перевикористовується — на нього посилаються картки прогресу.
- Ключ картки: `${exercise}:${itemId}`. Вправи: `recognize` (HU→UA), `recall` (UA→HU), `harmony` (вибір варіанта суфікса; з v0.5 картка = перевірений приклад `<id стема>+<id патерна>` — ті самі завдання, що й у Конструкторі, лише з патернами, де є ≥2 варіанти (`harmonyTasks`); усі комбінації «іменник × суфікс» більше не генеруються, бо дають невживані форми (postában); старі картки `harmony:<id стема>` переносить `migrateHarmony()` у `seed.ts`; режим набору тексту: `src/lib/settings.ts` — `setting:typing` у `meta` = `auto` (картка в review з інтервалом ≥ 7 днів) | `always` | `never`; набране слово порівнює `compare()` з `dictation.ts`: exact → Good/Easy, лише довгі голосні → Hard, інакше Again; спільне поле вводу з угорською клавіатурою — `src/components/HuInput.tsx`), `dictation` (TTS → ввід; `src/lib/dictation.ts`, слова з «/» чи «...» пропускаються), `builder` (UA → зібрати слово з блоків; `itemId` = `<id стема>+<id патерна>`, завдання беруться з `examples` патернів і з `examples` пакета (`{ pattern, stem, result, ua }` — приклади до суфіксів з інших пакетів) — `src/lib/builder.ts`).
- Контекст: `Pattern.frames` — міні-речення з «___» за роллю іменника / частиною мови / тегом (`transport`: «___ megyek.»), `*` — для всіх; приклад може перевизначити `frame` (-ról «про книжку» → «Beszélünk a ___.»). UA-рамка без прийменника — його несе глоса («Я ___.» + «у будинку»); у рамку йде лише перший варіант глоси до «;» і без «(дієслово)». `src/lib/frames.ts`: `frameFor`, `fillFrame` (a → az перед голосною, велика літера на початку). Кожен патерн мусить мати `frames` — інакше `content:check` попереджає.
- `Pattern.attachesTo` — до яких частин мови чіпляється суфікс (за замовчуванням лише noun); `attachesTag` — лише до слів з таким тегом (-ul/-ül → `language`); `short` / `shortByRole` — коротке пояснення для рядка результату (за роллю: -ról на людині = «про когось»); `roles` — з якими ролями іменників має сенс (`roleOf()` у `content.ts`: теги `group` (család, csapat, cég — група людей: без -on/-ra/-ig, але з -ban/-nak/-val) / `abstract` (betegség, veszély, biztonság — лише -ban/-ba/-ból/-ról/-tól/-ért/-val, -t/-k, присвійні, -i) / `person` / `place` / `time`|`day`|`month`|`season`|`daytime` / `food`|`drink`, інакше річ). Новий іменник-людину, групу, абстракцію чи місце обовʼязково тегувати, інакше «Гармонія» утворить apában чи családon. Приклади патернів мають точно дорівнювати `apply()` — інакше `content:check` падає. Підказки знахідного пишемо як «(дієслово) обʼєкт»: «(прошу) каву», бо «яблуко (що?)» не відрізняє відмінок.
- Суфікс на дієслові (-ás/-és, патерн `suf-nominal` в a2-07): `attachesTo: ["verb"]`, `attachesTag: "nominal"`, `fromInfinitive` — основа = інфінітив без -ni/-ani/-eni (`infinitiveStem()`), нерегулярна основа через `forms.stem` (vásárolni → vásárl, enni → ev, inni → iv, aludni → alv). Дієслово стає стемом «Гармонії» лише з полем `harmony` + тегом `nominal` — тегувати тільки регулярні (segíteni → segítség, játszani → játék — не тегувати).
- Гармонія голосних: клас стема (`back | front | front_rounded`) задається в контенті явно; `guessHarmony()` — лише fallback. Змішані слова (kávé → back) — винятки, тому тег обовʼязковий.
- `apply()` в `harmony.ts` подовжує кінцеві a/e (alma→almában; крім `noLengthen`: órakor), дає `-n` після голосної для `linking`-суфіксів (autón) і асимілює v для `assimilates` (-val/-vel: busz→busszal, hegy→heggyel). Знахідний, множина й присвійні (патерни з `inflect`) ідуть через `src/lib/inflect.ts`: сполучна голосна o/e/ö або a/e (`forms.low`), змінена основа (`forms.stem`: kéz → kez, tükör → tükr), -ja/-je (`forms.j`), повні винятки (`forms.p3: "anyja"`). Новий іменник = перевірити його форми в `npm run content:forms` і за потреби додати `forms`. Інші зміни основи (minden → mindent ok; -val після випадної голосної: tükörrel — ok) не моделюються. v-основи (hó/hav, tó/tav, ló/lov, kő/köv, fű/füv) моделюються лише в словозміні (`forms.stem` + `low`); відмінкові суфікси йдуть від словникової форми (hóban, tónál — ok; але -n після голосної дає lón/fűn замість lovon/füvön — відомий виняток, у приклади не класти).
- Пакети B1/B2: файли `content/b1-NN.json`, `content/b2-NN.json`, `level: "B1" | "B2"`; скрипти беруть `^[ab]\d-\d\d\.json$`; дієслова обовʼязково з `harmony` і `conj.tr` для перехідних (картки дієвідміни сіються автоматично). Генератори пакетів B2 — у скретчпаді сесії (`b2lib.py` + `gen-b2-NN.py`): попереджають про слова, що вже є в інших пакетах (дублікати стемів `content:check` не пропускає — такі слова лишаються в старому пакеті, а в новому на них лише посилаються приклади Конструктора).
- Пакети відкриваються послідовно: бос пакета N (`src/lib/boss.ts`, результат у `meta` як `boss:<id>`, поріг `BOSS_PASS` у `progress.ts`) відкриває N+1; `seedCards()` сіє лише відкриті пакети (`packIndexOf`, `taskPackIndex`). Новий пакет = додати в `content.ts` у кінець масиву `packs` — порядок і є порядком відкриття.
- Дієвідміна (`src/lib/conj.ts`, вправа `/conj`, картка `conj:<id дієслова>+<pres|past>.<indef|def>`, особа випадкова): форми теперішнього, минулого й майбутнього часу та можливості -hat/-het (fog + інфінітив; відокремлюваний префікс наперед: el fogok menni; `NOT_SEPARABLE` для beszélni/felelni/lélegezni; префікси в `PREFIXES` разом із tönkre/létre/újra; lenni → leszek), неозначена й означена відміна, виводяться з інфінітива + полів `conj` на дієслові: `tr` (перехідне → є означена відміна; це єдине семантичне поле, ставити обовʼязково), `ik` (-ik дієслово: lakom/lakik), `stem` (alszik → "alsz"), `vstem` (випадна голосна: érez → "érz"), `pastStem` (alud), `past` (група минулого: t | ott | full | tt, коли правило вгадує неправильно), `link: false` (áll: állsz, állnak), `forms` (повні перевизначення). Девʼять неправильних (menni, jönni, enni, inni, venni, vinni, tenni, hinni, lenni) зашиті в `conj.ts` і діють з префіксами (bevenni). Минулий час: кластер + сибілянт або l/r → голосна в усіх особах (tetszettem, elromlottam), -ll після короткої голосної теж (hallottam); випадна голосна з іншою основою минулого — `vstem` + `pastStem` (emlékszik / emlékezett); дієслова на голосну — `vstem` (nő → növök, nőttök, nőttem). Кожне дієслово мусить мати `harmony` (клас основи, не інфінітива: főzni → front_rounded; для основ лише з i/í/é — явно: írni back). Нове дієслово = `npm run content:conj` і переглянути його рядок; дієслова з пробілом (rendet rakni) не відмінюються. Наказовий спосіб (v0.8, час `imp`, картки `conj:<id>+imp.<indef|def>`): основа з -j (`impStem()`: після s/sz/z подвоєння — olvass, nézz, játssz; t після короткої голосної → ss — fizess, nyiss; після довгої чи приголосної → ts — taníts, érts; st/szt → ss/ssz — fess, válassz; інакше -j — várj, mondj, lőj), закінчення -jak/-j/-jon/-junk/-jatok/-janak та означені -jam/-d/-ja/-juk/-játok/-ják; коротка означена 2-ї особи = основа без -j + d (nézd, mondd, add, olvasd, fizesd, tanítsd, lődd); sz/d-дієслова беруть `pastStem` (alszik → aludj); відокремлюваний префікс іде після дієслова (menj el, nézd meg) — тому спурʼєзні префікси (előzni, túlórázni, betegeskedni) мусять бути в `NOT_SEPARABLE`, а справжні складені (felül, karban, egyet) у `PREFIXES`; `conj.imp` — перевизначення основи цілим словом (látni → "láss", megbocsátani → "megbocsáss") або `false`, коли наказу нема (tetszeni, illeni); неправильні — у таблиці `IRREGULAR` (egyél/edd, igyál/idd, vegyél/vedd, gyere/gyertek, légy). Умовний спосіб (час `cond`, картки `conj:<id>+cond.<indef|def>`): основа + n + закінчення (-nék/-nál/-na/-nánk/-nátok/-nának, означені -nám/-nád/-ná/-nánk/-nátok/-nák; 1sg неозначена завжди -nék), сполучна голосна як в -asz/-anak (mondanék, értenék, tanítanék; olvasnék, fizetnék — без), sz/d-дієслова через `pastStem` (aludnék), префікс лишається (megnézném), неправильні в `IRREGULAR` (ennék/enném, innék, vennék, mennék, lennék); минулий умовний (volna) — лише в довідці. Речення з пропуском (`src/lib/conjcloze.ts`): для картки шукається форма дієслова в прикладах і фразах усього контенту (спершу власний приклад), форма стає «___», особа береться з речення; без речення лишається синтетичне «(ő) ___ azt.» — тому новому дієслову варто давати `example` з його ж формою. Бос: 20% запитань — форма дієслова (`conjQuestion()` у `boss.ts`, речення або синтетичний рядок, часи з перевагою теперішнього й минулого). Довідка «Дієвідміна» (`src/components/ConjGuide.tsx`) рахує таблиці з тієї самої моделі.
- Речення (`src/lib/sentences.ts`, вправа `/sentences`, картка `sentence:<id>`): з перекладу й перемішаних слів зібрати угорське речення; джерела — `pack.sentences[]` (`{ id: "<pack>-sNN", hu, ua, note }` — три на пакет із поясненням порядку слів; `content:check` перевіряє id, 3–12 слів, кінцевий знак) та автоматично всі `example` і багатослівні фрази (3–12 слів, без «…», «/», «___»; дублікати за текстом відкидаються; нотатку підбирає `autoNote()` за ознаками: hogy, ha/mert/amikor, fog, питальне слово, nem/nincs/ne, «!», відокремлений префікс). Перше слово подається з малої літери, крім власних назв (слова, що трапляються з великої всередині речень) і Ön. Оцінка: з першого разу → Good/Easy, після помилки → Hard, «Показати» → Again. Приймається лише порядок з прикладу — нотатка пояснює, чому саме він.
- Словник (`src/lib/dictionary.ts`, сторінка `/dictionary`, посилання з головної та «Ще»): пошук по hu без акцентів (haz → ház, спершу точний збіг, потім початок, потім входження) або по ua; стаття показує переклад, роль, гармонію, пакет, приклад, таблицю форм (`formsFor()`: відмінки, присвійні, множина й прикметникові -bb/-an/-ság завжди, коли суфікс чіпляється; решта похідних (-i, -s, -ék, -nyi, -szerű, -nként, -kor, -ként…) лише якщо є приклад Конструктора для цього стема — щоб не показувати motori) і для дієслова повну дієвідміну (усі часи й способи; -hat/-het у таблиці форм не дублюється).
- План дня (`src/lib/day.ts`): кроки review → harmony → builder → conj → sentence; виконані за сьогодні зберігаються в `meta` як `day:<YYYY-MM-DD>`; `SessionDone` з пропом `step` відмічає крок і показує «Далі за планом»; на головній картка «План дня» з кнопкою «Почати/Продовжити день». Помилки (`src/lib/mistakes.ts`, сторінка `/mistakes`): картки, чия остання оцінка за 7 днів — Again; кнопка на сторінці пише `sessionStorage` `magyar:mode = mistakes:<page>` і відкриває вправу, яка через `takeMistakeMode(page)` один раз бере `mistakeCards()` замість `sessionCards()` (у «Картках» page = review для обох вправ); такий прогін кроку дня не відмічає.
- Статистика (`src/lib/statistics.ts`, сторінка `/stats`, посилання з головної та «Ще»): один прохід по картках і журналу повторень за 30 днів — календар 12 тижнів, повторення за тиждень проти мети (`setting:weeklyGoal` у `meta`, типово 150), точність (частка не-Again) і «знаю» (review з інтервалом ≥ 21 дня) за вправами, пакетами (`cardPackIndex`) і суфіксами (картки harmony/builder за патерном), найважчі картки за `lapses`.
- Діалоги (`src/lib/dialogues.ts`, вправа `/dialogues`, картка `dialogue:<id>`): `pack.dialogues[]` (`{ id: "<pack>-dNN", title, lines: [{ who, hu, ua }], question: { q, options, answer } }` — два на пакет, 3–6 реплік; `content:check` перевіряє id, репліки, запитання). Показ чергує два режими (`dealFor()`): запитання за змістом (українською, варіанти з контенту) або пропущена репліка — одна репліка після першої ховається, дистрактори беруться з реплік інших діалогів найближчих пакетів з тим самим типом речення (питання/твердження). Після відповіді під кожною реплікою переклад; «Показати переклад» доступно й до відповіді. Крок плану дня `dialogue`.
- Бос: 20 питань = 2 діалоги (запитання за змістом), 2 порядки слів (`sentenceQuestion()`: варіанти — явно хибні перестановки за `clearlyWrong()`: артикль без слова після, nem у кінці, питальне слово не першим; речення з комою не беруться), 3 дієвідміна, 5 форм із суфіксами, решта слова. Нагадування про копію прогресу на головній (`lastExport` у `meta`, пишуть «Поділитися» й «Експорт»; показується, коли ≥ 20 повторень і понад 7 днів без експорту/бекапу). Суфікси: -ható/-hető (`suf-potadj` у b1-09: verb + тег `potadj`, `fromInfinitive: "plain"`; лише правильні перехідні, enni/inni не тегувати), -beli (`suf-beli` у b1-03: noun, ролі place/group/time, `noLengthen`), -stul/-stül (`suf-sociative` у b1-06: `inflect: "stul"` — форма на -s + tul/tül: családostul, kutyástul). «Речення» в режимі набору (`setting:typing`): уся фраза через `HuInput`, порівняння без розділових знаків і регістру, лише довгі голосні → Hard.
- Будь-яка нова вправа = новий `Exercise` у `db.ts` + `ensureCards(...)` у `seedCards()` (`src/lib/seed.ts`; її викликають головна й кожна вправа перед завантаженням черги).

## Команди

Наприкінці кожної сесії, де щось закомічено, оновити журнал одним `batch`:

- `roadmap/<rNN-slug>` — `order`, `version`, `title`, `detail`, `status` (`done` | `next` | `todo`); тримати в синхроні з розділом «Що далі» нижче.
- `packs/<packId>` — `order`, `id`, `title`, `items`, `byKind` (за `pos`; фрази як `phrase`), `harmony` (`back`/`front`/`front_rounded`), `patterns[]`, `builderTasks` (числа — з `npm run content:check`).
- `meta/summary` — `updated`, `branch`, `inMain`, `packs`, `items`, `cards` (сума по вправах), `exercises[]` (`{ key, name, cards }`).
Перед записом у наявний документ прочитати його й передати `if_version`.
