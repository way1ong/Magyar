# Специфікація — Magyar v0.1

## Мета
Особистий застосунок для вивчення угорської на телефоні. Local-first, офлайн, без акаунтів. Ядро — інтервальні повторення (FSRS) і вправи, побудовані на механіці угорської (гармонія голосних, суфікси), а не лише на словнику.

## Рівні й контент
- Рівні за CEFR: A0 → A1 → A2 → B1. Кожен рівень — 8–10 пакетів по 80–120 елементів.
- Пакет (`content/<level>-<nn>.json`) містить `items` (слова, фрази), `patterns` (суфікси з варіантами за гармонією) і необовʼязкові `examples` — додаткові приклади `{ pattern, stem, result, ua }` до суфіксів з будь-якого пакета (напр. a1-03 «hétfőn — у понеділок» до -on/-en/-ön з a1-01). З усіх прикладів будуються завдання «Конструктора».
- Складність усередині рівня адаптивна: FSRS сам частіше показує те, що забувається.
- Пакети відкриваються послідовно: перший завжди, наступний — коли пройдено «Боса» попереднього (`meta.boss:<id>`, ≥ 80%). `seedCards()` сіє картки лише відкритих пакетів; уже посіяні картки ніколи не видаляються.

### Item
| поле | опис |
|---|---|
| `id` | стабільний, напр. `a1-01-haz` |
| `type` | `word` \| `phrase` |
| `hu`, `ua` | слово/фраза та переклад |
| `pos` | noun, verb, adj, adv, pron, num, phrase, other |
| `harmony` | `back` \| `front` \| `front_rounded` — для іменників/прикметників |
| `example` | `{ hu, ua }` |
| `tags` | вільні теги; семантичні ролі для іменників: `person`, `place`, `time` (також `day`/`month`/`season`/`daytime`), `food` (також `drink`), інакше — річ |

### Pattern
`id`, `name` ("-ban / -ben"), `meaning`, `forms: { back, front, front_rounded }`, `linking?` (суфікс зі сполучною голосною: після голосної лише `-n`), `attachesTo?` (частини мови, до яких чіпляється суфікс; за замовчуванням `noun`, `adj` — напр. `-szor` лише до `num`), `assimilates?` (-val/-vel: після приголосної v подвоює його — busszal, vonattal; подвоєний диграф пишеться ggy/ssz, три однакові — tollal), `attachesTag?` (суфікс лише для слів із цим тегом: -ul/-ül → `language`), `roles?` (з якими ролями іменників суфікс має сенс: -nak лише `person`, -ban — `place`/`thing`/`time`; «Гармонія» не пропонує apában чи asztalnak), `noLengthen?` (кінцеве a/e не подовжується: órakor), `examples[]` (`{ stem, result, ua }`; `result` має дорівнювати `apply()` — це перевіряє `content:check`).

## Вправи (v0.1)
| вправа | ключ картки | механіка | оцінка |
|---|---|---|---|
| Картки HU→UA | `recognize:<id>` | показати hu, відкрити ua + приклад | 4 кнопки FSRS |
| Картки UA→HU | `recall:<id>` | показати ua, згадати hu | 4 кнопки FSRS |
| Гармонія | `harmony:<id стема>` | іменник + випадковий патерн (лише ті, що пасують до його ролі — людина/місце/річ/час — і мають >1 варіант; прикметники лише з -ul/-ül) → обрати варіант суфікса | правильно швидко → Easy, правильно → Good, помилка → Again |
| Диктант | `dictation:<id>` | системний TTS озвучує hu, ввід тексту; порівняння без регістру й пунктуації | точно швидко → Easy, точно → Good, лише довгі/короткі голосні → Hard, інакше або «Показати» → Again |
| Бос | — (результат у `meta`: `boss:<id пакета>`) | 20 питань пакета упереміш без підказок: значення (hu→ua), слово (ua→hu), правильна форма (як Конструктор, але вибір серед 4 слів) | ≥ 80% — пройдено, відкриває наступний пакет; FSRS не чіпає |
| Конструктор | `builder:<id стема>+<id патерна>` | українське значення (`examples[].ua`) → зібрати слово з блоків: стем + 3–4 суфікси (правильний, інші варіанти гармонії, суфікси з іншим значенням). Відповідь — `apply()` | правильно < 5 с → Easy, правильно → Good, помилка → Again |

## Прогрес (IndexedDB)
- `cards`: стан FSRS по ключу + `exercise`, `itemId`, `due` (ms).
- `reviews`: кожна відповідь — `key, rating, ts, took`. Повний журнал зберігається назавжди.
- `meta`: ключ-значення (на майбутнє: параметри FSRS, налаштування).
- Бекап: експорт/імпорт JSON на екрані «Ще».

## Параметри FSRS
`request_retention 0.9`, `maximum_interval 180` днів, fuzz увімкнено. Після ~300 повторень — оптимізувати `w` з журналу (офлайн-скриптом) і покласти в `scheduler.ts`.

## Екрани
1. **Сьогодні** — стрік, повторень за день, карток у роботі; кнопки в картки й гармонію з лічильниками.
2. **Картки** — сесія до 30 карток обох напрямків упереміш, кнопка «Вимова» (системний TTS hu-HU).
3. **Гармонія** — сесія до 20 стемів; після відповіді озвучується готове слово.
4. **Конструктор** — сесія до 20 завдань; блоки торкаються по черзі (повторний дотик повертає блок), «Перевірити»; після відповіді — готове слово, озвучка й пояснення (подовження a→á, «-n після голосної»).
5. **Диктант** — сесія до 20 слів; кнопка «Послухати ще раз», ряд угорських літер (á é í ó ö ő ú ü ű) для вставки, «Показати» здається; слова з альтернативами («kettő / két») і пропусками («Hol van a ...?») не диктуються.
6. **Бос** — тест поточного (останнього відкритого) пакета; на головній — список пакетів зі станом 📖 / 🏆 / 🔒 і кнопка боса.
7. **Ще** — статистика, експорт/імпорт, скидання.
