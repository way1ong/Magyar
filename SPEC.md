# Специфікація — Magyar v0.1

## Мета
Особистий застосунок для вивчення угорської на телефоні. Local-first, офлайн, без акаунтів. Ядро — інтервальні повторення (FSRS) і вправи, побудовані на механіці угорської (гармонія голосних, суфікси), а не лише на словнику.

## Рівні й контент
- Рівні за CEFR: A0 → A1 → A2 → B1. Кожен рівень — 8–10 пакетів по 80–120 елементів.
- Пакет (`content/<level>-<nn>.json`) містить `items` (слова, фрази) і `patterns` (суфікси з варіантами за гармонією).
- Складність усередині рівня адаптивна: FSRS сам частіше показує те, що забувається.

### Item
| поле | опис |
|---|---|
| `id` | стабільний, напр. `a1-01-haz` |
| `type` | `word` \| `phrase` |
| `hu`, `ua` | слово/фраза та переклад |
| `pos` | noun, verb, adj, adv, pron, num, phrase, other |
| `harmony` | `back` \| `front` \| `front_rounded` — для іменників/прикметників |
| `example` | `{ hu, ua }` |
| `tags` | вільні теги |

### Pattern
`id`, `name` ("-ban / -ben"), `meaning`, `forms: { back, front, front_rounded }`, `linking?` (суфікс зі сполучною голосною: після голосної лише `-n`), `attachesTo?` (частини мови, до яких чіпляється суфікс; за замовчуванням `noun`, `adj` — напр. `-szor` лише до `num`), `examples[]` (`{ stem, result, ua }`; `result` має дорівнювати `apply()` — це перевіряє `content:check`).

## Вправи (v0.1)
| вправа | ключ картки | механіка | оцінка |
|---|---|---|---|
| Картки HU→UA | `recognize:<id>` | показати hu, відкрити ua + приклад | 4 кнопки FSRS |
| Картки UA→HU | `recall:<id>` | показати ua, згадати hu | 4 кнопки FSRS |
| Гармонія | `harmony:<id стема>` | стем + випадковий патерн → обрати варіант суфікса | правильно швидко → Easy, правильно → Good, помилка → Again |

## Прогрес (IndexedDB)
- `cards`: стан FSRS по ключу + `exercise`, `itemId`, `due` (ms).
- `reviews`: кожна відповідь — `key, rating, ts, took`. Повний журнал зберігається назавжди.
- `meta`: ключ-значення (на майбутнє: параметри FSRS, налаштування).
- Бекап: експорт/імпорт JSON на екрані «Ще».

## Параметри FSRS
`request_retention 0.9`, `maximum_interval 180` днів, fuzz увімкнено. Після ~300 повторень — оптимізувати `w` з журналу (офлайн-скриптом) і покласти в `scheduler.ts`.

## Екрани
1. **Сьогодні** — стрік, повторень за день, карток у роботі; кнопки в картки й гармонію з лічильниками.
2. **Картки** — сесія до 30 карток обох напрямків упереміш, кнопка «Вимова» (системний TTS hu-HU).
3. **Гармонія** — сесія до 20 стемів; після відповіді озвучується готове слово.
4. **Ще** — статистика, експорт/імпорт, скидання.
